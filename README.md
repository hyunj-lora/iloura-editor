# 이로우라 비포·애프터 카드 편집기

이로우라 지사에서 공통으로 사용하는 1:1 정사각형(1080×1080) 비포·애프터 카드뉴스 편집기입니다. 설치 없이 브라우저에서 바로 열어 쓸 수 있습니다.

- 사용 주소: https://hyunj-lora.github.io/iloura-editor/
- 파일: `index.html` (단일 파일 · 외부 라이브러리 없음)

## 주요 기능

- 5종 템플릿: 썸네일 요약 / 2분할 축 비교 / 2분할 부위 강조 / 3분할 경과 / 원인 포인트형
- 지사 공통·개별 설정: 상단 신뢰 문구·워터마크 토글, 하단 지사명 자동 저장
- 눈·턱 맞춤 가이드선(저장 이미지에는 포함되지 않음)
- 사진은 서버로 전송되지 않고 브라우저 안에서만 처리되며, `1080×1080 PNG`로 저장됩니다.

## 수정 방법

`index.html`을 고친 뒤 `main` 브랜치에 커밋·푸시하면 몇 분 안에 위 주소에 반영됩니다.

```bash
git clone https://github.com/hyunj-lora/iloura-editor.git
cd iloura-editor
# index.html 수정
git commit -am "편집기 수정"
git push
```
